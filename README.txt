JESIP INCIDENT ASSESSMENT PWA — UPDATED

Contains:
- M/ETHANE report generator
- JESIP principles prompts
- Railway WHAT behaviour assessment:
  W — What are they doing?
  H — How are they behaving?
  A — Are they alone or with others?
  T — What threat do they pose?
- HOT suspicious-item assessment
- Local autosave, clipboard copy, native email composer, print/save as PDF
- Offline caching after first load

Install:
Host these files on a static HTTPS web host. Open the URL on the phone and use the browser's Add to Home Screen / Install App option. Service workers and PWA installation require HTTPS except localhost.

Privacy:
The app does not send the form data to a server. Form data is stored in browser local storage on the device.

Operational note:
This is an unofficial reporting aid. Follow current railway security procedures, training, control-room instructions and current JESIP doctrine.
